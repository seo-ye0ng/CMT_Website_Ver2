> 회사소개서 내용을 반영, 회사소개·사업분야·솔루션·보안관제·컨설팅·OT Security가 중복되지 않도록 홈페이지 IA 개편안

**키워드**

`CMT EYES 보안관제` · `Network & Security` · `통합 유지보수` · `정보보호/클라우드/IDC 컨설팅` · `OT Security` · `AI-SOC 고도화`

## 1. 정리 원칙

> 핵심 정리: 회사소개는 “우리가 신뢰할 수 있는 회사인가?”를 증명, 사업분야는 “무엇을 제공하는가?”를 설명, 솔루션은 “어떤 제품/기술로 구현하는가? 구조로 분리

### 회사소개
개요, 연혁, 조직, 인력, 인증, 재무, 지사, 파트너/고객 등 기업 신뢰 정보

### 보안관제
CMT EYES, 24x365 관제, 침해대응, 장애대응, 관제상품 등 핵심 서비스

### 사업분야
SI/NI, 유지보수, 정보보호·클라우드·IDC 컨설팅, OT Security 등 고객 제공 서비스

### 솔루션
Fortinet, CATO, Juniper, Netscout, Radware, Qualys 등 제품군과 자체 플랫폼

## 2. AS-IS 중복 정리 방향

| 기존 이슈 | 개편 방향 |
| --- | --- |
| 회사소개와 사업분야 분리 | 회사소개는 신뢰자료, 사업분야는 제공 서비스로 분리 |
| 벤더 제품 중심 구조 | 고객 문제/보안 영역 중심 구조로 재배치 후 벤더는 솔루션 상세에 배치하며, 각각의 솔루션 소개서 다운로드 가능하도록 제공, 신규솔루션의 지속적 증가 대응 |
| 보안관제와 컨설팅 통합 | CMT EYES는 독립 메뉴로 강화, 컨설팅은 사업분야 하위로 통합 |
| 전국망/해외지사 노출 부족 | 회사소개 내 신뢰 인프라 항목으로 반영, 메인페이지내 회사소개서 다운로드 제공 |
| AI·플랫폼 메시지 약함 | AI-SOC 고도화, CMT 자체 플랫폼, 신사업 및 연구개발/Insight 메뉴로 반영 |
